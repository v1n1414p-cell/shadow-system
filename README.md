# SHADOW SYSTEM — Android

Projeto Android nativo em Kotlin/Java-ready, usando Gradle + Android Gradle Plugin. O app usa uma Activity nativa e armazenamento local via SharedPreferences.

## Abrir
1. Instale o Android Studio.
2. Abra a pasta `SHADOW_SYSTEM_ANDROID`.
3. Aguarde o Gradle Sync.
4. Execute em um emulador ou celular Android.
5. Para gerar APK: **Build > Build APK(s)**.

## Pacote
`com.shadowsystem.app`

## Funcionalidades desta base
- Dashboard SHADOW SYSTEM
- LV / XP / Rank E–S
- Barra de XP
- Streak
- XP total
- Peso
- Atributos
- Missões visuais
- Registro rápido de XP
- Registro de peso
- Persistência local
- LEVEL UP

A estrutura está pronta para expansão com Room, notificações, fotos de evolução, gráficos, navegação por telas e sincronização opcional.
